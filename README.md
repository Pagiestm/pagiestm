## À propos

Je conçois et je construis des produits web, du composant isolé jusqu'à la mise en production. Mon travail commence rarement par du code : je pose d'abord le problème, je regarde les contraintes réelles, puis je construis la plus petite chose qui répond au besoin — et j'itère avec les personnes qui utilisent l'outil.

- 🏢 **Développeur full-stack en alternance chez [Ailoop](https://www.ailoop.io/)** — outils digitaux sur mesure pour l'analyse de cycle de vie et les déclarations environnementales (ACV, FDES, EPD, DPP).
- 🎓 **MBA Développeur Full Stack — Manager de projet web digital** (niveau 7, BAC+5) à MyDigitalSchool Lille.
- 🧩 Front **et** back ensemble plutôt qu'une spécialisation d'un seul côté : React / Vue côté interface, NestJS / Node côté API et données.
- 🧪 Qualité logicielle : TDD, tests unitaires, E2E avec Playwright, CI/CD GitHub Actions, Docker et Terraform.
- 📬 **Ouvert aux opportunités** — CDI ou mission freelance. [pagiestm@gmail.com](mailto:pagiestm@gmail.com)
